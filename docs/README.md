# Documentation Guide

This folder keeps the public documentation short and useful.

If you have 5 minutes:

1. Read the main [README](../README.md)
2. Read [Architecture](architecture.md)

If you have 15 minutes:

1. Read [Deployment](deployment.md)
2. Read [Security](security.md)
3. Read [Roadmap](project-roadmap.md)

## What Each File Covers

- [architecture.md](architecture.md) - the workflow flow, components, and main hardening work.
- [architecture-diagram.svg](architecture-diagram.svg) - a static GitHub-friendly architecture view.
- [deployment.md](deployment.md) - what the runtime needs and what is intentionally not included in the public repo.
- [security.md](security.md) - the public-safe boundary and what was removed or hidden.
- [project-roadmap.md](project-roadmap.md) - the most useful next improvements for this repo.

## Reading Goal

This documentation is written for two audiences:

- employers who want to understand the project fast;
- engineers who want to see real structure without unsafe details.
