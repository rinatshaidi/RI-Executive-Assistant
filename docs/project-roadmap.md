# AI Mail Assistant Roadmap

## Goal

Keep the repository strong, honest, and easy to review.

The goal is not to make it bigger. The goal is to make it clearer.

## Now

The repository already includes:

- one real sanitized `n8n` workflow;
- a public-safe README;
- focused architecture, deployment, and security docs.

## Next Most Useful Improvements

- add a short sanitized case study about the broken `Google Sheets -> Telegram` path and its fix;
- add a safe import checklist for `n8n`;
- add one sanitized screenshot only after a separate review;
- add a validation note only after a fresh real rerun is safely confirmed.

## What Will Not Be Done

- no fake sample emails;
- no invented integrations;
- no private mailbox mapping;
- no production claims without evidence.
